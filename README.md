# 🙄 AI驚き屋バスター

X（旧Twitter）上の「AIすごい！」「○○終了！」「仕事がなくなる！」系の、過度に煽情的・誇張的なAI投稿をローカルでスコアリングし、折りたたみ／非表示にするChrome拡張です。

## Features

- ルールベースで「AI驚き屋度」を0〜100で推定
- しきい値以上のポストを折りたたみ、必要なら表示可能
- 完全非表示モード
- 投稿ごとの `🙄 驚き屋` / `違う` ボタンで投稿者単位の簡易学習
- 設定と学習データは `chrome.storage.sync` に保存
- 外部API・サーバー通信なし
- `x.com` / `twitter.com` 対応

## Install

1. このリポジトリをダウンロードまたはclone
2. Chromeで `chrome://extensions/` を開く
3. 「デベロッパー モード」をON
4. 「パッケージ化されていない拡張機能を読み込む」
5. このリポジトリのフォルダを選択
6. Xをリロード

## 判定ロジック

投稿本文の煽り表現に点数を付け、合計スコアが設定したしきい値以上なら検出します。

例:

- `エンジニア終了` / `仕事がなくなる`: +36
- `知らないと損`: +28
- `ゲームチェンジャー`: +24
- `これはヤバい`: +24
- `🤯`, `🚨`, `🔥🔥`: 加点

`🙄 驚き屋` を押すと、その投稿者に +15（最大 +50）。`違う` を押すと -15（最小 -40）されます。

## Privacy

判定処理はブラウザ内だけで実行されます。投稿本文やアカウント情報を外部へ送信しません。

## Known limitations

- XのDOM構造変更により動かなくなる可能性があります。
- ルールベースのため誤検知・見逃しがあります。
- 引用ポストや長文ポストでは本文抽出が完全ではない場合があります。
